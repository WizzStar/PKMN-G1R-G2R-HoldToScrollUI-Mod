# G1R HoldToScrollUI Mod for Gen1Recomp
**v1.0.4** · by **WizzStar**

> Hold the D-pad in menus and keep scrolling. No more tapping through long lists — and it never messes with anything outside UI.

**Repo:** [PKMN-G1R-HoldToScrollUI-Mod](https://github.com/WizzStar/PKMN-G1R-HoldToScrollUI-Mod)

## ✨ Features
- **Hold to Scroll** — Up / Down keeps moving the cursor after a short delay
- **Hold to Step** — Left / Right keeps changing option values
- **Menus Only** — overworld walking is never affected
- **Works with Other Mods** — any UI that reads `wasPressed` usually just works
- **Speed Ladder** — REPEAT SPEED **1–5** (default **3** = the tuned feel)
- **Hold Delay** — tweak how long before the first repeat

## ⚙️ Defaults
- **AUTO SCROLL** — ON
- **HOLD DELAY** — 16 frames
- **REPEAT SPEED** — **3**
